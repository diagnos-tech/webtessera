webtessera

A Tessera transparency log running entirely in this tab and stored in IndexedDB. Open this page in a second tab: both append to the same log, and the Web Locks API makes them take turns.

Demo only. The log's private signing key is generated in this browser and kept in localStorage, where any script on this origin can read it. A real log never exposes its key to the page.
